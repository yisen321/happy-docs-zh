移动端访问#

只需配对一次 iPhone 或 Android 版 Happy 应用，电脑上的每个会话就都能在手机上访问，并采用端到端加密。智能体仍在你的机器上运行，使用你的文件，并遵守你的权限边界。

要配对手机，只需告诉参谋长：

  • 示例

    配对我的手机

将手机与 Happy Desktop 配对#

打开设置 → 移动端访问，或在初始引导过程中操作。

  1. 从 App Store 或 Google Play 安装 Happy。Desktop 会显示应用商店页面的二维码。
  2. 扫描 Desktop 随后显示的设备二维码，并在手机上批准这台电脑。只需扫描一次。

已经关联过的电脑会直接复用，无需再次扫码。

已经在使用原版 Happy CLI？你的账号和会话仍然可用。从设置 → 移动端访问连接 Desktop；CLI 和 Desktop 会作为同一账号下的两台机器显示在手机上。

手机同步如何加密#

手机持有账号的主密钥。内容在一台设备上加密，在另一台设备上解密。中继服务存储并转发无法解读的数据块；它能看到机器和会话的存在以及它们何时活跃，但看不到其中的内容。完整说明见安全与加密。

你可以在手机上做什么#

  • 发送消息及加密图片。
  • 回应权限请求和问题。手机上的回复是可信回答。
  • 停止当前轮次。
  • 切换模型与推理强度，更改权限模式。
  • 在某个目录中发起会话。如果目录不存在，系统会发起创建请求，绝不会悄悄执行 mkdir。
  • 在与智能体相同的权限边界内，读取文件及会话的 Git 改动。

移动端访问故障排查#

  • 绝不要删除或重置 ~/.happy。其中保存着历史记录、配置和账号状态。
  • 已保存的关联可能处于离线状态；Desktop 只有在实时状态确认连接时才显示“已连接”。
  • 手机丢失或已保存账号冲突时，需要通过对话处理恢复。在你作出选择前，保留两端状态。
