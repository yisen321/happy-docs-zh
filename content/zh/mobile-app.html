在手机上使用 Claude Code 和 Codex#

Happy 手机应用是 Happy 的移动端。Happy 是一个开源智能体运行框架，可在你的电脑上编排 Claude、Codex、Grok、Gemini 等智能体。iPhone 和 Android 版本均可免费使用。用二维码配对手机一次，之后就能随时随地发送消息、回应权限请求、切换模型以及查看改动。智能体会继续在你的机器上运行，同步过程采用端到端加密。

我可以通过手机控制 Claude Code 吗？#

可以。扫描二维码，将 Happy 应用与 Happy Desktop 配对一次。此后，你就能通过手机启动会话、发送消息、回应权限请求、切换模型和查看改动，而智能体会继续在你的电脑上运行。

也支持 Codex、Grok 和 Gemini 吗？#

支持。Happy 使用你已付费的订阅来运行 Claude、Codex 和 Grok，Gemini 及任何 ACP 智能体则使用各自的登录账号（测试版）。手机上会显示它们的全部会话。

我需要使用终端吗？#

不需要。Happy Desktop 会负责运行智能体。如果你已经在使用原版 Happy CLI（npm 上的 happy），同一个手机应用也能与它配合使用。

我的电脑必须一直开机吗？#

是的，因为智能体在电脑上运行。若希望笔记本休眠时它们仍继续工作，可以在远程服务器上运行 Happy Agent，再通过同一个手机应用访问。

费用是多少？#

应用免费，并采用 MIT 许可证。语音是我们唯一收费的功能；详见语音。

配对#

在 Happy Desktop 中打开 Settings → Mobile Access（设置 → 移动访问）。从 App Store 或 Google Play 安装 Happy，扫描 Desktop 显示的设备二维码，然后在手机上批准这台电脑。只需扫描一次。

已经在使用原版 Happy CLI（npm 上的 happy）？同一个手机应用也能与它配合使用；参见其文档。

你能在手机上做什么#

离开电脑时，会话所需的一切操作：发送带图片的消息、回应权限请求、停止当前轮次、切换模型、新建会话，以及查看文件和 Git 改动。完整列表见移动访问。

隐私#

会话采用端到端加密，因此 Happy 中继只能看到密文；参见手机同步的加密方式。
