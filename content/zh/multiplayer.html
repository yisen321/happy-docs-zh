多人协作与团队#

为整个团队运行一个 Happy Agent：这是一台自托管的编程智能体服务器，在你掌控的机器上运行 Claude、Codex 和 Grok。每位成员通过 Happy Desktop 登录自己的 Happy Social 账号、配对自己的手机，并在共享项目和会话中工作，遵守与个人机器相同的沙箱和审查规则。这台服务器就是一台切换到团队模式的普通远程服务器。

要创建团队，只需询问参谋长：

  • 示例

    在我的服务器 ubuntu@203.0.113.10 上创建名为 Acme 的团队，并邀请 alice@example.com

Happy 团队服务器如何工作#

  • 登录。每位成员在 Desktop 中连接自己的 Happy Social 账号（Settings → Account → Connect account（设置 → 账号 → 连接账号）），通过 WorkOS 登录。随后，其 Desktop 会获得该团队的短期 WorkOS 令牌。服务器会在每次请求（包括健康检查）时核验令牌：签名正确、团队正确且未过期。其他情况统一返回 401。参见团队登录的工作方式，以及如何改用自己的身份提供商。
  • 传输。Tailcat 是无需 Tailscale 账号的 WireGuard：不开放端口，流量端到端加密，Tailscale 的免费中继能看到地址和时间信息，但看不到内容。地址携带预共享密钥，因此请保密；即使陌生人拿到地址，也只能走到登录检查这一步。参见 Happy 如何使用 Tailcat。
  • 手机。每位成员选中团队服务器后，从 Settings → Mobile Access（设置 → 移动访问）配对自己的手机。手机通过 Happy 中继而非 Tailcat 连接：服务器将每位成员的会话以端到端加密方式发布到各自的 Happy 账号，因此即使服务器离线，手机也能读取。草稿按成员分别保存。
  • 共享工作。所有人看到相同的项目和会话。每当发言人变化，系统会以姓名和邮箱告知智能体当前是谁。这只是告诉智能体谁在说话，不会授予任何权限。草稿及每个人任务列表的排序仍各自独立。
  • 提供商账号。Claude、Codex 和 Grok 的登录账号归属于服务器的服务账号。每位成员的工作都使用这些账号及其额度；不会使用成员自己的订阅。
  • 沙箱和审查。规则与你自己机器上的相同。只读、工作区写入以及默认的自动模式，都会在操作系统沙箱中运行每条命令；在自动模式下，将跨越沙箱边界的操作会先经过审查，每次审查一个操作。完全访问模式会移除沙箱，任何成员都可以将会话切换为该模式。在 Ubuntu 24.04 上，管理员需要先为守护进程可执行文件授予 AppArmor 命名空间许可。
  • 所有者。创建团队的人是团队所有者。只有所有者可以重命名安装实例、启停全局技能，或归档其他成员的任务。除此以外，成员拥有相同的访问权限。

如何建立、加入和离开团队#

建立。参谋长会确认你的 Happy Social 账号，按照远程服务器指南在服务器上安装 Happy Agent，创建团队，将服务器切换至团队模式，并从你的 Desktop 运行一个真实任务。完成这些后才会询问你要邀请谁。团队模式下，服务器只接受该团队的 Happy Social 登录，仅通过 Tailcat 监听，不保留本地套接字或令牌。所有步骤都在公开操作指南创建并部署 Happy 团队中。

加入。接受邮件邀请，在 Desktop 中使用该邮箱连接 Happy Social，然后请你的参谋长连接团队。

离开。我们尚未实现移除成员的操作。停止服务器会同时断开所有人的访问。

与他人共享自己的电脑#

你可以让他人使用你自己机器上的 Happy Agent。不过，除非对方是家人，或是你愿意把已解锁笔记本电脑交给的人，否则最好不要这样做。

目前唯一的方法是把你的连接信息交给对方：启用 Tailcat（向参谋长说“启用 Tailcat”），然后私下发送地址、端口，以及 ~/.happy/agent/token 中的 API 令牌。对方在自己的机器上添加一个 [connections.<id>] 条目，或者请其参谋长添加连接。

此后，对方就等同于你：

  • 所有内容都共享。包括你的项目、会话、参谋长、设置和个人资料。智能体无法区分你们。
  • 由你的账号承担用量。对方的工作使用你的 Claude、Codex 和 Grok 订阅、你的 Git 身份，以及项目能推送到的任何目标。
  • 沙箱由对方选择。在自动模式中，shell 命令不能写入工作区外的位置、访问未列入允许名单的域名，或读取 ~/.ssh、~/.aws、~/.claude 和 ~/.codex 等凭据文件夹；但智能体的文件工具仍可读取这些目录及主目录中的其他内容。对方可以将任何会话切换到完全访问模式，从而移除沙箱。MCP 服务器始终在沙箱外运行。

目前没有按会话邀请的功能。在你自己的机器上使用团队模式，可以让每个人拥有独立身份，但会关闭你自己的 Desktop 使用的本地套接字，因此团队模式应放在独立机器上。

撤销访问：请参谋长关闭 Tailcat，连接会立即关闭。然后在 happy.toml 中设置新的 [api] token，并重启 Happy Agent；旧令牌将失效。重新启用 Tailcat 会恢复相同地址，因此必须在重新启用前轮换令牌。

尚未实现的功能#

目前，团队设置需要有意识地分多个步骤完成。我们尚未实现从侧栏添加或移除队友的功能。
