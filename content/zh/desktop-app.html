适用于 Claude Code、Codex、Grok 和 Gemini 的开源桌面应用#

Happy Desktop 是一款免费、采用 MIT 许可证的应用，可在 macOS、Windows 和 Linux 上协调运行 Claude Code、Codex、Grok、Gemini 等，并复用你已经付费的订阅。通过 Homebrew 或 GitHub 即可安装。不同于 Claude Desktop 中的 Code 页签或 ChatGPT 应用中的 Codex，它可以运行各厂商的代理，而且代码开放。iOS 和 Android 应用则是手机端的另一半：访问相同会话，并进行端到端加密。

对比其他应用#

Anthropic 和 OpenAI 都为各自的代理提供了桌面应用：Claude Desktop 中的 Code 页签，以及 ChatGPT 桌面应用中的 Codex。我们于 2026 年 10 月 9 日核对了它们的文档。

如果你只使用一家厂商，并希望在新功能发布当天就用上，厂商自己的应用会更适合。Claude Desktop 还提供 Happy 没有的功能，例如云端会话、计算机操作和 iOS 模拟器面板。Happy 适合希望在自己的电脑上，将多家厂商的代理集中到一处运行，并且能够阅读其代码的用户。

T3 Code 是另一款支持多家厂商代理的开源应用。参见 Happy 与 T3 Code 对比。

统一框架，每个模型保持原生#

Claude 使用 Claude Code 的提示词和工具，GPT 模型使用 Codex 的，Grok 使用 Grok Build 的。模型周边的能力全部共享：统一的权限模型、沙箱和工具集。你可以随时更换模型或推理强度，对话记录会保持不变。每个子代理都可以选择自己的模型，因此同一项任务可以用一家提供商的模型规划，用另一家的模型审查。Happy 也可以改为运行厂商的完整代理（测试版）：适用于 Gemini 的 Antigravity、Claude Code、Codex、OpenCode，或任何支持 Agent Client Protocol（ACP）的代理。参见模型与订阅。

使用现有订阅，无需密钥#

在电脑上登录 Claude Code、Codex 或 Grok CLI，Happy 就会使用这些凭据。访问模型无需购买 Happy 套餐，也无需粘贴密钥。请求使用你的凭据直接发往厂商；Happy 绝不代理这些请求。

关闭窗口，会话仍在#

无界面运行时 Happy Agent 将所有会话保存在你电脑上的数据库中。退出应用后，会话仍会继续运行。重启运行时后，会从磁盘恢复。参见工作原理。

权限与沙箱#

新会话默认使用 Auto 模式。读取和工作区编辑自由执行，其他操作均在操作系统沙箱内运行；少数跨越边界的操作由独立代理自动审核。不会弹出提示打断你。参见权限与沙箱。

手机访问，全程加密#

将 iOS 或 Android 上的 Happy 应用配对一次，即可在手机上访问电脑上的每个会话，并享有端到端加密。中继只能看到密文。参见在手机上使用 Claude Code。

获取应用#

下载 macOS、Windows 或 Linux 版本，或在 macOS 或 Linux 上运行 brew install --cask slopus/tap/happy。快速开始将带你从安装走到完成首项改动。源代码位于 GitHub：应用及其代理运行时。
