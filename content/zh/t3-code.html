Happy 与 T3 Code 对比#

Happy 和 T3 Code 都是免费、采用 MIT 许可证的应用，可通过桌面应用或手机，使用你已经付费订阅的账户运行 Claude、Codex 和 Grok 智能体，也都能通过 Agent Client Protocol（ACP，智能体客户端协议）运行其他编程智能体。如果你需要网页客户端、应用开发工具，以及原生 Cursor、Pi 和 Muse Code 集成，选择 T3 Code。如果你需要每个人都以自身身份登录的自托管团队服务器、让 Claude、Codex 和 Grok 在同一沙箱下运行的统一执行框架，以及默认开启的审查，则选择面向团队的 T3 Code 替代品 Happy。

T3 Code 更擅长的方面#

  • 原生集成。Cursor 通过其 SDK 运行，Pi 通过其 RPC 模式运行，Muse Code 通过其 SDK 运行。Happy 只能通过 ACP 接入它们。
  • 网页客户端。app.t3.codes 可从任何浏览器通过 HTTPS 或 T3 Connect 访问机器。
  • 可编辑的排队消息。消息保存在服务器上，你可以编辑、删除，或将其中一条作为引导消息发送。
  • 应用开发工具。对话线程旁可显示实时 iOS Simulator 或 Android Emulator，可以与智能体共享浏览器标签页，还能处理 GitHub、GitLab、Bitbucket 及另外四个平台上的拉取请求。
  • 访客链接（测试版）。通过 T3 Connect，让别人连续 24 小时在浏览器中查看一个对话线程；对方的消息会等待你发送后才发出。

为团队运行一台智能体服务器#

Happy Agent 可在你掌控的机器上以团队模式运行。每位成员通过 Happy Social（经 WorkOS）或你自己的身份提供商，以自身身份登录。所有人在同一批项目、会话和任务中工作，遵循相同的沙箱与审查规则，智能体也会获知当前发言者。每位成员配对自己的手机。手机通过 Happy 的中继进行端到端加密连接，因此服务器离线时也能阅读聊天。

T3 Code 没有成员独立登录：你通过具有范围限制的访问权限将设备配对到机器，并通过访客链接分享一个对话线程。

目前团队设置需要多个步骤。我们尚未提供移除成员操作，成员的工作使用服务器上的 Claude、Codex 和 Grok 账户。参见多人协作与团队。

所有模型共用一个执行框架#

默认情况下，Happy Agent 自行运行智能体循环。Claude 使用 Claude Code 的提示词和工具，GPT 模型使用 Codex 的，Grok 使用 Grok Build 的。权限模型、操作系统沙箱和会话存储是共享的。在对话中途切换模型，新模型会从同一份对话记录继续，各提供商的数据保持发送时的原貌。

Happy 也能运行厂商自己的智能体（测试版）：通过 Agent SDK 运行 Claude Code，通过 codex app-server 运行 Codex，或运行任何支持 ACP 的智能体。大多数编程智能体都提供 ACP 命令或适配器：Cursor 有 agent acp，fx 有 fx acp，Pi 有 pi-acp，Muse Code 有非官方适配器，Antigravity 和 OpenCode 也有各自的实现。不必逐个点击设置页面。告诉你的智能体，它就会把执行框架加入 happy.toml。对话仍保留在 Happy 中，Happy 的权限模式会映射到该智能体自己的权限模式。

T3 Code 始终运行各厂商的智能体，其中 Antigravity、Grok Build、fx 和注册表智能体通过 ACP 运行。切换提供商时，短对话完整转移；较长对话则变为受预算限制的内容选集，默认 16,000 个 token，不包含原提供商的推理或工具状态。智能体可以使用工具查阅剩余内容。

默认 Auto，而不是完全访问#

Happy 的新会话以 Auto 模式开始。命令在操作系统沙箱内运行，只有会越过沙箱边界的操作才交给独立智能体审查。读取和工作区编辑从不等待审查，因此审查不会妨碍正常工作，我们也看不出默认关闭它的理由。参见权限与沙箱。

T3 Code 的新对话线程以完全访问模式开始：命令和编辑无需审批提示即可执行。你可以在设置中选择其他默认模式。其 Auto 使用各提供商自己的自动审查机制，遇到 OpenCode、Antigravity 等没有此机制的提供商时则退回询问用户。

在一轮执行中途更新#

智能体工作时也能安装 Happy Agent 更新：当前步骤完成并保存后，新版本启动，同一轮执行随即继续。窗口不会重新加载。参见执行中途更新。

T3 Code 默认会在更新或重启后恢复受支持的对话线程。其文档指出，服务器更新可能先中断正在运行的智能体和终端命令。

用脚本驱动#

Happy Agent 的 REST API 可在本机或远程机器上发送消息、引导正在执行的一轮任务、停止执行，以及回答智能体的问题。参见通过 REST API 驱动 Happy Agent。T3 Code 提供供外部智能体使用的 MCP 服务器，以及主机上的 t3 thread 命令。

参与贡献#

两者均采用 MIT 许可证。我们接受拉取请求，优先处理 Bug 修复。截至 2026 年 10 月 27 日，T3 Code 的 README 写道：“我们目前（大体上）还不接受贡献。可能会考虑小修复，但不会接受大型功能。”
