Happy 与 Claude Code Remote Control 对比#

Claude Code Remote Control 是针对单个 Claude Code 会话的远程控制功能：这是 Anthropic 内置的方式，让你通过 Claude 应用或浏览器继续该会话。Happy 则是用于编排编程智能体的开源运行框架：在一个桌面应用中使用 Claude、Codex、Grok、Gemini 等智能体，复用你已有的订阅，并通过端到端加密的手机应用访问每个会话。如果只想继续一个 Claude 会话，不想额外安装软件，Remote Control 更简单。

Remote Control 的优势#

  • 无需安装。如果你使用 Claude Code 和 Claude 应用，只需运行 claude remote-control，或在会话中运行 /remote-control，然后扫描二维码。
  • 官方提供。它可在 Claude Code CLI、Claude Desktop 应用和 VS Code 扩展中使用，并由 Anthropic 提供支持。
  • 任意电脑上的浏览器。所有会话都能在 claude.ai/code 打开。
  • 管理员控制。Team 和 Enterprise 所有者决定是否启用。Trusted Devices 将访问权限与已注册设备及近期登录关联。
  • 深度集成 Claude Code。已连接的设备可以查看子智能体进度、上下文压缩和差异面板，还可以运行 /compact、/model 等命令。

Happy 的不同之处#

  • 不止 Claude。Happy Desktop 可并排运行 Claude、Codex、Grok、Gemini 等智能体，并可在对话过程中切换模型。所有会话都能通过同一个手机应用访问。
  • 端到端加密。内容在一台设备上加密，在另一台设备上解密。Happy 中继存储和转发无法解读的数据块；它能知道会话存在，但看不到内容。参见安全与加密。
  • Bedrock。Happy Desktop 可通过 Amazon Bedrock 运行 Claude 和 GPT 模型，而 Remote Control 不支持这一场景。
  • 会话寿命不受窗口限制。在 Happy Desktop 中，会话存在于运行时而非应用中，重启后仍能保留。
  • 开源。手机应用、Happy Desktop 和 Happy Agent 均采用 MIT 许可证。你可以阅读代码、创建分支副本并发布自己的构建版本。
