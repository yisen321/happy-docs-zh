最初的 Happy CLI#

最初的 Happy CLI（npm 上的 happy，原名 happy-coder）仍然可用，同一个 Happy 手机应用既能访问它，也能访问 Happy Desktop。它目前处于维护模式：继续获得关键修复，而新功能在 Happy Desktop 中推出。

CLI 的作用#

npm install -g happy

happy claude
happy codex

happy 使用你平常的登录和参数来包装真正的 claude 或 codex，在会话离开电脑之前进行加密，并维持后台守护进程，让手机可以在没有连接终端的情况下启动和恢复会话。首次运行时，通过二维码配对电脑。完整参考见原版 Happy CLI 文档。

将 CLI 与 Happy Desktop 一起使用#

  • Desktop 不依赖 CLI，也不会安装它。
  • 你的账户和会话仍然可用。从设置 → 移动访问配对 Desktop 后，手机会将 CLI 和 Desktop 显示为同一账户下的两台机器。
  • 两者都将状态保存在 ~/.happy 中。绝不要为了修复问题而删除它。

转用 Happy Desktop#

Happy Desktop 在一个应用中运行 Claude、Codex、Grok、Gemini 等，并复用你已经付费的订阅。会话由后台运行时管理，因此关闭窗口或重启后仍能保留，而且每个会话都可以在手机上访问。下载应用，或从快速开始入手。
