隐私政策

最后更新：2026 年 10 月 11 日

关于 Happy

Happy 是一款适用于 Claude Code 和 Codex 的免费、开源移动端及网页客户端，采用 MIT 许可证发布。源代码公开可用，任何人都可以按照 MIT 许可证的条款对其进行审查、修改和分发。

数据收集

Happy 通过 PostHog 收集有限的、使用假名标识的产品分析数据。我们利用这些数据了解核心操作是否成功，并更早发现问题。分析数据绝不包含你的消息内容、代码或其他加密的会话内容。

  • 我们记录简单的产品操作及其结果，例如连接、发送消息、开始或结束语音会话，以及应用更新。
  • 事件可能包含应用、操作系统和设备详情等基本技术信息，以便我们诊断可靠性问题。
  • 分析使用的是采用假名标识的应用标识符，而不是你的代码或对话内容。
  • 你可以在应用设置中关闭分析功能。

本网站 happy.engineering 通过 PostHog 记录页面浏览和点击情况，与应用使用同一个 PostHog 项目。网站不设置 Cookie，也不在你的浏览器中存储任何内容，因此每次访问均单独计数；PostHog 根据我们的项目设置处理 IP 地址。

加密的会话数据

你的消息、代码和会话数据在发送前会先在你的设备上加密。Happy 的中继仅存储用于同步设备的加密数据块，无法读取其中的内容。

为了提供同步和通知功能，Happy 会处理有限的服务元数据，包括设备、会话及消息标识符、时间戳和推送通知令牌。这些元数据不是你的代码或对话内容。

第三方服务

Happy 可能会根据你的配置连接 Claude Code 和 Codex 等外部 AI 服务。使用这些服务时：

  • 你须遵守相应服务的隐私政策和服务条款。
  • Happy 不会将你的代码或对话内容发送至 PostHog。
  • 推送通知通过 Expo 的推送通知服务发送；推送令牌仅用于发送通知。

独立性

Happy 是一个独立、由社区驱动的项目。我们与 Anthropic、Claude 或任何其他 AI 服务提供商不存在关联或隶属关系，也未获得其认可。Happy 是一款对接各种 AI API 的第三方客户端。

开源承诺

作为一个采用 MIT 许可证的开源项目：

  • 所有源代码均公开，可供审查。
  • 你可以自行核实我们的隐私实践。
  • 你可以自由修改和分发本软件。
  • 我们欢迎社区贡献和安全审查。

隐私政策的变更

由于 Happy 是开源项目，本隐私政策的变更将反映在源代码仓库中。我们建议你定期查看仓库以了解更新。
