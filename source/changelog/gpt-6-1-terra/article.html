GPT-6.1 Terra, newest models first#

Happy Agent v0.4.108 · October 26, 2026 · All releases

We've added GPT-6.1 Terra through Codex in Happy's model picker.

The picker now lists the newest generation first within each provider: every GPT-6.1 model appears above every GPT-6 model.

We've removed GPT-5.6 models from the picker. If a chat uses GPT-5.6, switch it to another model before continuing.

Stops survive restarts#

Stopped conversations stay stopped after Happy Agent restarts, and your next message no longer waits behind an unwanted reply. Work interrupted by a crash still resumes.

Bots and tasks can set up MCP#

Bots and tasks can configure MCP servers in their own folders, alongside the servers available across your installation and projects.

More stable inline pages#

Updated artifact guidance helps agents build inline pages that keep a steady height as their content changes.

Stem cells Beta#

Happy Desktop v0.0.102 · October 25, 2026 · Share this release

Start work with Create. Just say what you want done. It names itself, grows its own icon, and the sidebar self-organizes: a focus agent sorts it by topic. Bigger sidebar changes arrive as proposals you can accept or keep editing.

Beta, off by default. Turn on Settings → Experimental → Stem cells. The switch enables the new sidebar, Create and the focus agent together. The focus agent's proposals need Happy Agent 0.4.107 or newer.
