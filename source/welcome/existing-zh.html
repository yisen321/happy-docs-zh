欢迎#

Happy 是一个开源的编程智能体运行与编排框架：在同一款桌面应用中使用 Claude、Codex、Grok、Gemini 等智能体，并沿用你已经付费的订阅。智能体可以将工作交给使用其他模型的子智能体，在统一的权限模型与沙箱下运行，并在重启后继续工作。手机应用、远程服务器和团队协作也都是其中的一部分。

下载适用于 macOS、Windows 或 Linux 的版本并打开。Happy 会启动自己的智能体运行环境，并自动使用本机已有的 Claude、Codex 和 Grok 登录状态。

你将获得什么#

  • 每个模型，都有原生体验。Claude 使用 Claude Code 的提示词和工具，GPT 模型使用 Codex 的，Grok 使用 Grok Build 的。Gemini 在 Google 的 Antigravity 中运行，也支持运行任何兼容智能体客户端协议（ACP）的智能体（测试版）。切换模型后，对话记录仍会保留。
  • 编排。使用任意模型的子智能体、可以相互发消息的智能体、定时消息，以及持久运行的机器人。
  • 沿用你的订阅。访问模型无需 Happy 账号。凭据来自本机已有的 Claude Code、Codex 和 Grok CLI 登录状态。
  • 参谋长。应用中的第一个机器人。通过对话，它就能帮你配置 Happy：添加模型账号、导入项目、配对手机、部署远程智能体、创建团队，以及升级 Happy。
  • 持久会话。即使关闭窗口或重启，每段对话和每个子智能体也都会保留，并在收到下一条消息时带着完整上下文继续工作。
  • 自动模式。读取操作和工作区内的编辑无需审批即可执行。其他所有操作都由操作系统沙箱隔离。少数跨越沙箱边界的操作会自动接受审查，不会弹出提示要求你确认。
  • 工作区。并行任务拥有各自独立分支上的 Git 工作树（worktree）。
  • 手机。在适用于 iPhone 和 Android 的 Happy 应用中访问同样的会话，并采用端到端加密。中继服务器仅传输密文。
  • 多人协作。部署一台团队服务器，即可共同工作。每个人以自己的身份登录，共享相同的项目与会话。
  • 技能与 MCP。通过 Markdown 文件和 TOML 配置条目定义，两者都可以由智能体编写。
  • MIT 许可证。阅读源码、派生项目（fork），发布你自己的构建版本。

Happy 如何收费？#

Happy 免费提供，并采用 MIT 许可证；模型使用你自己的 Claude、Codex 和 Grok 订阅。我们唯一收费的项目是手机应用中的语音功能：每 30 天免费提供 20 分钟，之后通过应用内订阅可获得每 30 天最多 5 小时的用量。如果使用你自己的 ElevenLabs 智能体，Happy 不设用量限制。详见语音。
