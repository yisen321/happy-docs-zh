The Open Source Desktop App for Claude Code, Codex, Grok, and Gemini#

Happy Desktop is a free, MIT-licensed app for orchestrating Claude Code, Codex, Grok, Gemini, and more on macOS, Windows, and Linux, reusing the subscriptions you already pay for. Install it with Homebrew or from GitHub. Unlike the Code tab in Claude Desktop or Codex in the ChatGPT app, it runs every vendor's agents, and its code is open. The iOS and Android app is the phone half: the same sessions, end-to-end encrypted.

How it compares#

If you use one vendor and want its newest features the day they ship, its own app is the better fit. Claude Desktop also does things Happy does not, such as cloud sessions, computer use, and an iOS Simulator pane. Happy is for running several vendors' agents in one place, on your own machine, with code you can read.

T3 Code is another open-source app for several vendors' agents. See Happy vs T3 Code.

One harness, every model native#

Claude gets Claude Code's prompts and tools, GPT models get Codex's, and Grok gets Grok Build's. Everything around the model is shared: one permission model, one sandbox, one set of tools. Change the model or reasoning effort as you go and the transcript stays. Subagents each pick their own model, so one task can plan on one provider and review on another. Happy can also run a vendor's whole agent instead (beta): Antigravity for Gemini, Claude Code, Codex, OpenCode, or any Agent Client Protocol (ACP) agent. See Models & Subscriptions.

Your subscriptions, no keys#

Sign in to Claude Code, Codex, or the Grok CLI on the machine and Happy uses those credentials. There is no Happy plan for model access and no key to paste. Requests go to the vendor with your credentials; Happy never proxies them.

Sessions that outlive the window#

A headless runtime, Happy Agent, holds every session in a database on your machine. Quit the app and sessions keep running. Restart the runtime and they resume from disk. See How It Works.

Permissions and the sandbox#

New sessions start in Auto. Reads and workspace edits run freely, everything else runs in the OS sandbox, and the few actions that cross the boundary are reviewed automatically by a separate agent. You are not prompted. See Permissions & Sandbox.

Your phone, encrypted#

Pair the Happy app for iOS or Android once. Every session on the computer is on the phone, end-to-end encrypted. The relay sees ciphertext only. See Claude Code on your phone.

Get it#

Download for macOS, Windows, or Linux, or run brew install --cask slopus/tap/happy on macOS or Linux. The Quick Start takes you from install to a first change. The source is on GitHub: the app and its agent runtime.
