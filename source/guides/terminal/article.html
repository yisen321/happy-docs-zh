The Original Happy CLI#

The original Happy CLI (happy on npm, formerly happy-coder) still works, and the same Happy phone app reaches both it and Happy Desktop. It is in maintenance mode: it gets critical fixes, and new features ship in Happy Desktop.

What the CLI does#

npm install -g happy

happy claude
happy codex

happy wraps the real claude or codex with your normal sign-in and arguments, encrypts the session before it leaves the machine, and keeps a background daemon so the phone can start and resume sessions with no terminal attached. The first run pairs the machine by QR code. The full reference is in the original Happy CLI docs.

Use the CLI alongside Happy Desktop#

  • Desktop does not need the CLI and does not install it.
  • Your account and sessions keep working. Pair Desktop from Settings → Mobile Access, and the phone shows the CLI and Desktop as two machines on the same account.
  • Both keep their state under ~/.happy. Never delete it to fix a problem.

Move to Happy Desktop#

Happy Desktop runs Claude, Codex, Grok, Gemini, and more in one app, reusing the subscriptions you already pay for. Sessions belong to a background runtime, so they survive a closed window and a restart, and every one of them reaches your phone. Download it, or start at the Quick Start.
