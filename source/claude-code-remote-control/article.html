Happy vs Claude Code Remote Control#

Claude Code Remote Control is a remote for one Claude Code session: Anthropic's built-in way to continue it from the Claude app or a browser. Happy is an open-source harness for orchestrating coding agents: Claude, Codex, Grok, Gemini, and more in one desktop app, reusing your subscriptions, with an end-to-end encrypted phone app that reaches every session. To continue one Claude session with nothing extra to install, Remote Control is simpler.

Where Remote Control is better#

  • Nothing to install. If you use Claude Code and the Claude app, run claude remote-control, or /remote-control in a session, and scan the QR code.
  • First-party. It works from the Claude Code CLI, the Claude Desktop app, and the VS Code extension, and Anthropic supports it.
  • A browser on any computer. Any session opens at claude.ai/code.
  • Admin controls. Team and Enterprise owners decide whether it is on. Trusted Devices ties access to an enrolled device and a recent sign-in.
  • Deep Claude Code integration. Connected devices see subagent progress, compaction, and a diff pane, and can run commands like /compact and /model.

Where Happy is different#

  • More than Claude. Happy Desktop runs Claude, Codex, Grok, Gemini, and more side by side, and a conversation can change models as it goes. Every session reaches the same phone app.
  • End-to-end encryption. Content is encrypted on one device and decrypted on another. Happy's relay stores and forwards opaque blobs; it sees that sessions exist, not what is in them. See Security & Encryption.
  • Bedrock. Happy Desktop runs Claude and GPT models through Amazon Bedrock, where Remote Control is not available.
  • Sessions that outlive the window. In Happy Desktop a session lives in the runtime, not the app, and survives a restart.
  • Open source. The phone app, Happy Desktop, and Happy Agent are MIT licensed. Read the code, fork it, ship your own build.
