本仓库是 [Happy Engineering 官方文档](https://happy.engineering/welcome/)的中文静态翻译版本，不是 Happy 官方网站，不代表官方提供支持、承诺或产品服务。产品名称、原站内容与相关商标归原权利人所有。涉及权限、安全、价格及兼容性时，请结合原文与实际版本核实。

- 中文站点：https://yisen321.github.io/happy-docs-zh/ （实际发布状态以仓库 GitHub Pages 设置为准）
- 原站：https://happy.engineering/
- 官方源码：https://github.com/slopus/happy
- 翻译范围：完整 51 页，包括七组导航中的 45 页、四篇更新详情，以及隐私政策与服务条款两篇法律页面。导航仍保持七组45项，更新详情从正文链接进入，法律页面从页脚进入。
- 不包含：官网营销首页、下载页面及旧版 `/docs/`、`/docs/security/`；这些链接保留为官方外链。
- 法律页面仅为 Happy 官方政策的非官方中文翻译，不将官方政策主体改成本中文站，也不代表本中文站作出同等政策承诺；应以每页标明的官方原文为准。
- 页面保留原欢迎页的布局、桌面双滚动区、两套导航与移动端展开交互，不依赖第三方 Python 包、外部 CSS 或在线字体。

## 内容与构建

仓库中的清单使用 `content/manifest.json`，记录每页 slug、原文 URL、中文标题、输出路径及原文快照路径。完整中文正文存放在 `content/zh/<slug>.html`，内容为原站 `document-content` 容器的内部 HTML；嵌套 slug 同样使用嵌套目录。欢迎页还可使用 `templates/welcome.zh.html` 的既有完整译文。上述路径均相对于仓库根目录。

原文代码块、命令、JSON、配置项与接口标识保留字面量，不用英文原文冒充中文，不用摘要替代整页翻译。缺页、缺译文、采集失败或无中文正文时，构建会失败，不会用英文或占位页兜底。

在任意目录执行，先把示例中的绝对路径替换为你自己的仓库路径。

```sh
python3 -I /你的仓库绝对路径/tools/build_site.py
python3 -I /你的仓库绝对路径/tools/build_site.py --check
```

默认构建完整站点，欢迎页输出到根 `index.html`，其他页面按清单的 output 输出。运行前确保没有未保存的生成页改动，因为构建会更新这些文件。只有全部页面成功渲染并完成静态链接检查后，才开始写入生成文件。

`--check` 只读验收现有站点，不会重新构建或写文件。它检查全部译文及生成文件、7 组 45 项导航、当前页状态、代码块未因构建改变、站内目标文件与锚点，以及已翻译文档是否仍误链到官网。页脚标记为原文来源的链接是明确保留的例外。

## 链接与离线限制

所有已翻译的站内文档链接使用相对 HTML 文件路径，保留查询参数和 fragment，兼容直接打开本地 HTML（`file://`）与 GitHub Pages 项目子路径。当前页锚点保留，导航按原顺序排列，折叠导航在当前页所在分组自动展开。

图片、视频和其他原站资源使用绝对来源 URL，不自动下载或内联未知站点资源。因此正文与站内跳转可离线使用，但原站图片、视频及官方外链仍需要联网。

## 后续更新

1. 更新原文快照和清单，核实原文是否新增、删改段落及代码。
2. 逐页同步完整中文正文，保留原文标题锚点与代码，不只改页面标题。
3. 运行构建，再运行只读静态验收。
4. 核实生成变更后，由维护者提交并按 GitHub Pages 配置发布。构建脚本本身不会提交、推送或部署。

中文译文可能存在滞后或理解偏差。每页底部提供对应原文地址，欢迎对照原文提出修正。
