与智能体对话：基于 ElevenLabs 的语音功能#

在手机上的 Happy 应用中，点一下麦克风就能说话。一个同样叫作 Happy 的语音智能体会倾听，将你的请求发送给当前查看会话中的编程智能体，在完成时告知你，并接收你对权限请求的同意或拒绝。它运行在 ElevenLabs 的对话式智能体平台 ElevenAgents 上。语音是 Happy 唯一收费的功能：每 30 天免费 20 分钟，之后需要订阅；也可以使用你自己的 ElevenLabs 智能体，这种方式不受我们的用量限制。

语音智能体会做什么#

  • 只有对它说话时才回应。它会回应“Happy，……”或明确的后续提问。其他情况下，它会跳过自己的发言，因此你可以与身边的人交谈。每次只说一句话。
  • 它是桥梁，不是程序员。它不会自行作决定。它会认为你正在口述并组织最终要交给编程智能体的请求，等你表达完整后才发送。
  • 跨会话工作。它会先获取你的活动会话列表，跟随你当前聚焦的会话，同时接收其他会话的更新。
  • 反馈结果。编程智能体完成工作时，即使你没有说话，语音智能体也会告诉你。
  • 语音处理权限。工具权限请求会被朗读给你。只有你明确说出决定，它才会允许或拒绝，除非你告诉它接受之后的请求。
  • 使用你的语言。在设置 → 语音中设置语音智能体的语言。

对话如何开始#

  1. 应用携带你的 Happy 登录身份及我们 ElevenLabs 智能体的 ID，向 Happy 服务器请求一次对话。
  2. 服务器根据你的 Happy 用户 ID，使用服务器密钥进行单向哈希，生成你的 ElevenLabs 用户 ID。你的 Happy 账号不会发送出去；ElevenLabs 看到的是这个 u_… 字符串。
  3. 服务器向 ElevenLabs 查询你过去 30 天的对话并汇总时长。记录保存在 ElevenLabs；我们不维护语音数据库。
  4. 如果未超限，服务器会在该用户 ID 下向 ElevenLabs 签发一次性对话令牌并返回。超过限制时，应用改为显示付费提示。
  5. 应用使用该令牌与 ElevenLabs 建立 WebRTC 会话。从这里开始，Happy 服务器不再参与：音频直接在手机与 ElevenLabs 之间传输。

我们的 ElevenLabs 智能体只接受 Happy 服务器签发的令牌，因此开源应用中的智能体 ID 本身不会带来风险。

ElevenLabs 会接触哪些内容#

设备之间的消息采用端到端加密。语音功能会从手机端将其中部分已经解密的内容发送给第三方。

  • 你的麦克风音频，以及智能体的回复；
  • u_… 用户 ID 和系统提示词；
  • 活动会话的 ID 与摘要；
  • 当前聚焦会话的项目路径、摘要，以及最多 50 条历史消息，包括你的消息、编程智能体的文本，以及它使用过的工具名称与描述，但不包括工具参数或输出；
  • 新到达的消息，以及每个权限请求中的工具名称与参数；
  • 每次对话的记录，Happy 服务器读取这些记录来统计分钟数。

如果某个会话中包含你不愿交给第三方的内容，就不要在该会话上开启语音。

用量限制#

档位每 30 天
免费20 分钟
已订阅5 小时
自有 ElevenLabs 智能体Happy 不设限
所有用户100 次对话

ElevenLabs 给我们带来的成本约为每分钟一美分。应用内订阅用于支付这部分费用，并支持我们的开源工作。100 次对话的上限来自用量查询的限制，因为它最多读取 100 次对话；达到上限后，语音会被阻止，直到统计窗口向前移动。如果遇到这种情况，值得提交一个 issue。设置 → 语音会显示已用分钟数、对话次数及相应上限。

使用自有智能体#

在设置 → 语音 → 使用自有智能体中，填入你自己的 ElevenLabs 账号下的智能体 ID。应用随后会通过该智能体直接连接 ElevenLabs，不再为语音功能调用 Happy 服务器：不统计分钟数，不显示付费墙，费用记在你的 ElevenLabs 账单上。设置智能体 ID 后，应用会显示配置该智能体的提示词指南。

Happy Desktop 上的 GPT-Live#

Happy Desktop 还有自己的实验性语音通话功能，使用 OpenAI 的 GPT-Live，而不是 ElevenLabs。开启设置 → 通用 → 启用实验性功能，再开启设置 → 实验性功能 → 语音通话，然后选择账号：Codex 订阅会使用 ChatGPT 套餐中的 gpt-live-1-codex；OpenAI API 密钥则使用 gpt-live-1，费用计入该 API 账号。设置旁会出现一个电话按钮。通话由你机器上的 Happy Agent 使用所选账号运行，因此不受 Happy 的分钟数和付费墙限制。它操作的是 Desktop 窗口，而不是编程智能体：它会导航并准备好消息，由你按下发送。

为什么选择 ElevenLabs#

一个能持续倾听、处理中途打断并流畅回应的语音智能体，本身就是一款产品。ElevenAgents 为我们提供了这些能力，还提供每次对话独立的令牌，让我们的智能体只接受服务器签发的令牌；它提供的对话记录也让我们无需维护自己的数据库就能统计用量。感谢 ElevenLabs。
